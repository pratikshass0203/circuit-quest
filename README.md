# ⚡ Circuit Quest

[

An interactive, gamified platform for learning digital electronics — build circuits, solve logic puzzles, battle a CPU boss, and master waveforms through hands-on challenges instead of textbooks.

## 🎮 About

Circuit Quest turns electronics theory into a game. Learners progress through themed modules — from basic logic gates to CPU architecture — solving interactive problems, tracking progress, and unlocking harder challenges as they go.

## ✨ Features

- **Multiple Game Modules**: Circuit Builder, Gate Puzzler, Power Quest, State Machine, Waveform Lab, CPU Boss
- **Interactive Problem/Solution Engine** with a built-in Question Player
- **User Authentication** (sign up / login via Supabase)
- **Progress Tracking & Curriculum Map** to visualize learning paths
- **Subscription/Pricing tiers** with a market/competitive comparison view
- **Progressive Web App (PWA)** — installable, works offline
- **Roadmap** page for upcoming features

## 🛠️ Built With

- **React** + **TypeScript** — UI and component logic
- **Vite** — build tool and dev server
- **Tailwind CSS** — styling
- **Supabase** — authentication, database, and migrations
- **PWA** (Service Worker + Manifest) — offline support & installability
- **SQL** — question banks and problem sets seeded via migration scripts

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- A [Supabase](https://supabase.com/) project (for auth & database)

### Installation

```bash
git clone https://github.com/your-username/circuit-quest.git
cd circuit-quest
npm install
cp .env.example .env
# Add your Supabase URL and anon key to .env
npm run dev
```

The app will be available at http://localhost:5173.
